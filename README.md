# Cometcart

Find anything. Compare every price. Save what you love.

A mobile-friendly shopping site for South African shoppers. See `CLAUDE.md` for the full brief and build order.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open http://localhost:3000 in your browser.

## Where things live

- `src/app/` – the pages (Home, Discover, Wishlist, Add a product)
- `src/components/` – reusable pieces (header, product card, search bar, assistant)
- `src/data/placeholder.ts` – sample content for the home screen (replaced in step 5)
- `public/images/` – product photos, with their licences in `LICENCES.md`
- `reference/` – the clickable prototype (not saved to Git: its photos are unlicensed)
